# API Contract & Data Model

Base path: `/api` (served by CloudFront → Lambda Function URL). All responses JSON unless stated.

## Common request headers

| Header | Required | Notes |
|---|---|---|
| `x-auth-token` | yes (all routes) | Cognito **access token**. NOT `Authorization` (reserved for OAC SigV4). |
| `x-amz-content-sha256` | yes for requests with a body | lowercase hex SHA-256 of the exact request body bytes. |
| `content-type` | with body | `application/json` |
| `x-ui-lang` | optional | `ja` or `en` — UI language, used only as a reply-language tie-breaker |

## Errors

Non-2xx responses: `{ "error": { "code": string, "message": string } }`

| Status | code |
|---|---|
| 400 | `bad_request` (validation) |
| 401 | `unauthorized` (missing/invalid token) |
| 404 | `not_found` |
| 429 | `quota_exceeded` (daily limit reached) |
| 500 | `internal` |

## Routes

### `POST /api/chat` — streaming
Request:
```json
{ "sessionId": "optional-uuid", "message": "string, 1..4000 characters (Unicode code points)" }
```
If `sessionId` is omitted a new session is created (title = first ~40 code points of message).
The session row and both messages are written in one transaction **only after the answer completes**; if the stream
ends with `error`, nothing is saved and the `sessionId` from the `session` event does not exist (the UI should drop it).

Response: `200`, `content-type: application/x-ndjson`. One JSON object per line, in this order:
```jsonc
{"type":"session","sessionId":"uuid","title":"..."}
{"type":"citations","citations":[Citation, ...]}      // retrieved sources, numbered 1..n
{"type":"delta","text":"partial text"}               // many
{"type":"done","messageId":"uuid","usage":{"inputTokens":123,"outputTokens":456}}
```
On failure after streaming has started: `{"type":"error","message":"..."}` and the stream ends.
Quota/auth/validation errors before streaming starts return normal JSON error responses (401/429/400).

`Citation`:
```ts
{
  n: number;               // 1-based; model cites as [n]
  source: "pmbok" | "user";
  edition?: "6" | "7";     // for pmbok
  title: string;           // e.g. "PMBOK Guide 7th Edition"
  page?: number;           // from KB location metadata if available
  excerpt: string;         // <= 300 chars of the retrieved chunk
  score?: number;
}
```

### `GET /api/sessions`
`200 { "sessions": [ { "sessionId", "title", "createdAt", "updatedAt" } ] }` — newest first (sorted by `updatedAt`).

### `GET /api/sessions/{sessionId}`
`200 { "session": {...}, "messages": [ { "messageId", "role": "user"|"assistant", "content", "citations"?: Citation[], "createdAt" } ] }` — oldest first. `404` if not owned by caller.

### `DELETE /api/sessions/{sessionId}`
`204`. Deletes session item and its messages.

### `GET /api/me`
`200 { "sub", "username", "usage": { "date": "YYYY-MM-DD", "count": number, "limit": number } }`

### Phase 2 (not in POC core)
- `POST /api/uploads` → `{ uploadUrl, key }` presigned PUT to `uploads/<sub>/<uuid>-<filename>` (PDF/DOCX/TXT/MD, ≤ 10 MB)
- `GET /api/documents` → list caller's uploads + ingestion status

## DynamoDB (single table)

Table `PmbokTable` (name generated by CDK; passed as env `TABLE_NAME`). Keys: `PK` (S), `SK` (S). On-demand billing. TTL attribute `ttl`. PITR off (POC).

| Entity | PK | SK | Attributes |
|---|---|---|---|
| Session | `USER#<sub>` | `SESSION#<sessionId>` | `sessionId, title, createdAt, updatedAt` |
| Message | `USER#<sub>#SESSION#<sessionId>` | `MSG#<createdAt ISO>#<messageId>` | `messageId, role, content, citations?, usage?, createdAt` |
| Usage | `USER#<sub>` | `USAGE#<YYYY-MM-DD>` | `count, inputTokens, outputTokens, ttl (+35 days)` |

- Ownership is enforced by key construction: every key includes the caller's `sub` from the verified JWT.
- Quota check: `UpdateItem` with `ADD count 1` and `ConditionExpression: attribute_not_exists(count) OR count < :limit` → `ConditionalCheckFailed` ⇒ 429. Date in **Asia/Tokyo** timezone.
- History for the prompt: query messages for the session, `ScanIndexForward=false`, `Limit = 2 * HISTORY_TURNS`.
